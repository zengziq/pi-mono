> 目标：不懂技术也能在 30~60 分钟内看清这个仓库的业务逻辑、关键流程与机会点。

## 推荐阅读顺序

1. [01-overview.md](./01-overview.md)  
   先建立全局心智模型：这个仓库是干什么的、解决什么问题、价值在哪里。
2. [02-user-journey.md](./02-user-journey.md)  
   从用户视角看“谁在用、怎么用、哪里卡”。
3. [03-core-flows.md](./03-core-flows.md)

4. [04-risk-and-opportunities.md](./04-risk-and-opportunities.md)  
   站在决策视角看风险、机会、优先级与 90 天路线图。

---

## 你可以先看这 5 个结论

1. 这是一个 **AI Agent 产品家族平台**，不是单点工具。  
2. 核心价值在于 **“统一模型 + 可执行 Agent + 多入口协作（CLI/Web/Slack）”**。  
3. 真正的业务护城河不是模型本身，而是 **流程沉淀、组织协作和治理能力**。  
4. 产品化优先级应先做 **安全与稳定闭环**，再做扩展和增长。  
5. 对非技术团队最友好的落地路径是：**模板化任务 + 可视化流程 + 可追踪结果**。

## 学习打法（建议）

- **第 1 轮（30 分钟）**：只看每篇的“结论 + 可执行建议”。
- **第 2 轮（60 分钟）**：重点看 Mermaid 图，把图串成你的业务链路。
- **第 3 轮（90 分钟）**：按上面的代码目录做“图 -> 代码”映射，验证理解。

如果你在学习中新增了自己的业务假设，建议追加到 `docs/explain/` 形成“你的版本”。
